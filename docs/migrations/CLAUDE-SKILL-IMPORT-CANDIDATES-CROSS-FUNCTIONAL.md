# Claude Skill Import Candidates: Cross-Functional

It is intentionally filtered:
- toward cross-functional utility
- away from obvious overlap with current Lamella skills
- away from tool-specific automations that only make sense if we adopt that exact external stack

## Filter Notes

- Prefer imports that are reusable across multiple teammate roles.
- Deprioritize skills that are mostly wrappers around a specific SaaS or MCP integration unless you plan to support that integration directly.
- Deprioritize skills that duplicate established Lamella workflows unless the external version is materially better.
