# Claude Skill Import Candidates: Fun and Delight-Oriented

This shortlist captures import candidates from `potential-claude-skills/` that feel fun, playful, visually interesting, or broadly enjoyable for teammates to use.

It is intentionally filtered:
- toward creative and delight-heavy skills
- away from purely utilitarian automation
- away from obviously redundant Lamella imports unless the tone or interaction pattern is notably different

## Import First

These feel like the strongest "fun additions" that are still practical enough to justify importing.

## Shortlist Summary

If the goal is to add a few imports that feel genuinely enjoyable, I would start with:

1. `design-spells`
2. `3d-web-experience`
3. `theme-factory`
4. `algorithmic-art`
5. `slack-gif-creator`
6. `screenshots`
7. `storyboard`
8. `customer-journey-mapping-workshop`

## Notes

- The best fun imports are the ones that make output feel more expressive, visual, or collaborative, not just more optimized.
- The Antigravity repo has the richest pool for fun imports, but it also has the widest quality spread, so those candidates should be adapted rather than copied blindly.
- The Superpowers repo has strong process skills, but most of the interesting ones overlap Lamella's existing authoring and workflow coverage.
