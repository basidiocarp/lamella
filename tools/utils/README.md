# Utility Scripts

General-purpose utility scripts.

## Scripts

| Script | Description |
|--------|-------------|
| `bridge.py` | Bridge between planning formats |
| `bridge-plan-schema.json` | JSON schema for bridge plans |
| `rtk-benchmark.sh` | RTK performance benchmarking |
| `sonnetplan.sh` | Sonnet-based planning utility |

## Usage

```bash
# Run bridge
python scripts/utils/bridge.py --help

# Benchmark
./scripts/utils/rtk-benchmark.sh
```
